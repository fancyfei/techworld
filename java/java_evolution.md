# Java 语言和发展

> 1. *计算机语言分类：机器语言，汇编语言，高级语言*
> 2. *计算机语言翻译的方式：编译，解释，混合（编译解释型）*

Java 是一种非常流行的高级编程语言。它类似 C++，吸收了 C++ 的诸多优点，去掉了其中不易理解的部分，并提供了自动内存管理（垃圾回收）、取消了指针、不支持类的多重继承，因此使用起来更简单。

Java 是编译解释型语言。源代码先通过编译器编译成 class 字节码，再由解释器（或即时编译器）把字节码转成机器码执行。

Java 最重要的特点是跨平台性、面向对象、开源，因此长期位居编程语言流行榜前列。

跨平台的原理是：Java 程序被编译为字节码格式，运行在 JVM 中，不同系统的 JVM 解决对应系统的运行时，实现"一次编写，到处运行"。

也正因为开源，各个领域都有围绕 Java 构建的生态，如Web 应用、大数据、人工智能等等。

## Java 分为三个体系

* Java SE：Java 平台标准版，整个 Java 的基础和核心，三个体系的基础，也可单独用于桌面应用开发。
* Java EE：Java 平台企业版，用于企业级 Web 应用开发，这是 Java 使用最多的领域，也是 Java 生态所在。现由 Eclipse 基金会维护，更名为 Jakarta EE。
* Java ME：Java 平台微型版，用于嵌入式电子产品开发，现已基本停止演进。


## Java 重要特征

* 面向对象：提供类、接口和继承等特性，类之间为单继承。
* 分布式：提供了用于网络应用编程的类库。
* 健壮：强类型机制、异常处理、垃圾自动收集，并丢弃了指针。
* 安全：提供了安全管理机制。
* 跨平台：字节码运行在 JVM 上，由不同系统的 JVM 解决运行时差异。
* 多线程：线程是 Java 提供的一种特殊的对象，并提供了相关的控制接口。
* 动态性：Java 程序需要的类能够动态地被载入到运行环境。

## JVM 上的其他语言

JVM 不只能跑 Java。只要编译成字节码，其他语言也能在 JVM 上运行，并直接调用 Java 类库。主流的有：

- Kotlin：JetBrains 出品，语法简洁，是 Android 官方开发语言，后端也在普及。
- Scala：融合面向对象与函数式，大数据领域 Spark 的核心语言。
- Groovy：动态语言，Gradle 构建脚本用的就是它。
- Clojure：Lisp 方言，主打不可变数据与并发。

## 发展历程

### Sun 时代（1995—2006）

- 1995 年 5 月 Java 诞生，Sun 公司推出，原名 Oak，由 James Gosling 和同事们共同研发，目标定位在开发 Internet 应用程序。
- 1996 年 1 月 JDK 1.0 正式发布，包括 JVM、Applet、AWT。
- 1997 年发布 JDK 1.1，包括 JAR、JDBC、JavaBean、RMI、内部类、反射等。
- 1998 年发布 JDK 1.2，里程碑式的版本，重要功能有 Swing、JIT、EJB、集合等。此后更名为 Java 2，体系拆分为 J2SE、J2EE、J2ME，HotSpot 虚拟机随后成为默认虚拟机，并成立了 JCP 组织负责标准定制。
- 2002 年发布 JDK 1.4，相当多的新特性：正则、异常链、NIO、日志、XML、丰富的 API。

> 这是 Java 真正走向成熟的里程碑式版本，Java 生态圈多数都是基于这个版本发展起来的，多数框架在此后 10 多年依然支持它。

- 2004 年发布 J2SE 5，主要是语言层面的易用性改进：自动装箱拆箱、泛型、动态注解、枚举、可变长参数、增强 for 循环等。

> Java 语言发展史上的又一里程碑。正式改名为 Java SE、Java EE、Java ME，版本号从 5 开始，随后又取消了 2 这个数字。对程序员友好的改进都集中在这个版本。

- 2006 年发布 Java SE 6，支持动态脚本语言和许多改进项。

> 同年 Java 正式开源，形成了 OpenJDK。此后 SUN 衰落，Java 更新缓慢。

### Oracle 时代（2010 至今）

2010 年 Oracle 并购 Sun，而且对社区并不友好。

- 2014 年发布 Java 8，重要特性有 Lambda 表达式、Stream API 等，并修改了内存模型。

> 至今仍是存量使用最多的版本，但新项目已普遍转向 17 及以后。

- 2017 年发布 Java 9，重点是模块系统。此后每半年发布一个大版本，Java 10 加入了局部变量类型推断（var）。

从 Java 11 起，长期支持版改为约两年一个：11、17、21、25。中间的半年版本多为增量改进，下面只挑变化较大的版本介绍。

### Java 11（2018，LTS）

Java 8 之后第一个长期支持版：标准 HTTP Client、ZGC（超低延迟垃圾回收器）、Flight Recorder 转为开源，并移除了 Java EE 和 CORBA 模块。

### Java 17（2021，LTS）

密封类（sealed class）正式定版，限制哪些类可以继承；强封装 JDK 内部 API；移除 RMI 激活、实验性 AOT 编译器等老旧组件。这是当前很多企业的生产版本。

### Java 21（2023，LTS）

- 虚拟线程正式定版：轻量级线程，大幅降低高并发服务器的开发成本，是 Loom 项目的核心成果。
- switch 模式匹配正式定版，record 模式匹配正式定版，语言的模式匹配主线基本收官。
- 分代 ZGC、有序集合（Sequenced Collections）等。

### Java 25（2025，LTS）

- Scoped Values 正式定版：替代 ThreadLocal，更适合虚拟线程的上下文传递。
- 紧凑源文件与实例 main 方法：写小程序不再需要 `public static void main` 和类声明。
- 灵活构造函数体：允许在调用 `super()` 或 `this()` 之前写校验逻辑。
- 结构化并发、模式匹配支持基本类型等预览特性持续打磨。

> 自此移除 32 位 x86 支持。当前 LTS 序列为 8、11、17、21、25。

## JDK 发行版

Java 开源后形成了 OpenJDK，这是官方参考实现，社区共建，免费使用。

Oracle 自己的 Oracle JDK 从 Java 11 起改为商业许可，商用需付费（Java 8 的更新也受此约束），因此多数企业转用 OpenJDK 或其下游发行版（如 Eclipse Temurin、Amazon Corretto、阿里 Dragonwell 等），免费且可获得长期支持。

目前的普遍做法是：生产环境使用 OpenJDK 下游发行版。
