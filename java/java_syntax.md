# Java 基础语法

基本注意点：

- 大小写敏感。类名首字母大写（大驼峰），方法名、变量名首字母小写（小驼峰）。
- 标识符由字母、数字、下划线、$ 组成，不能以数字开头，不能使用关键字。
- 关键字是语言预留的单词，如 public、static、class、void 等。
- 源文件名必须与 public 类名相同。
- 所有程序的入口是 `public static void main(String[] args)`，args 接收命令行参数。
- javac 编译，java 执行。
- 注释：单行 `//`，多行 `/* */`，文档注释 `/** */`。

## 基本数据类型

Java 提供八种基本类型：六种数字类型（byte/short/int/long 四个整型，float/double 两个浮点型），一种字符类型 char，一种布尔类型 boolean。

- 整型：byte/short/int/long，8/16/32/64 位，取值范围依次翻倍。long 字面量要加 L 后缀（如 10L），否则按 int 处理。
- 浮点型：float/double，32/64 位，有不同的取值范围和精度。float 字面量要加 f 后缀（如 3.14f），否则按 double 处理。
- 字符型：char，16 位，表示单个 Unicode 字符，用单引号表示（如 'a'），转义以 \ 开头（\n 换行、\t 制表符、\ 反斜杠本身）。
- 布尔型：boolean，只有 true/false 两个值。

```
类型和对应的取值范围
byte: -2^7 ~ 2^7-1
short: -2^15 ~ 2^15-1
int: -2^31 ~ 2^31-1
long: -2^63 ~ 2^63-1
float: 1.4E-45 ~ 3.4E+38 和 -3.4E+38 ~ -1.4E-45
double: 4.9E-324 ~ 1.7E+308 和 -1.7E+308 ~ -4.9E-324
```

> 小数计算的结果不精确。需要精确计算时，一般用 BigDecimal 类，或先转成整型算出结果再转回小数。

## 引用类型

除基本类型外都是引用类型，包括类、接口和数组。变量里存的是对象的引用（可理解为指针），访问内容用 `.`（对象）或 `[]`（数组）。

null 是一个特殊的字面值，可以赋给任何引用类型变量，表示不引用任何对象。`String.class` 这类 class literal 表示类型本身，`instanceof` 运算符用于判断一个对象是否属于某类型，结果是布尔值。

每种基本类型都对应一个包装类。基本类型和包装类之间从 Java 5 起可以自动转换（自动装箱/拆箱），属于语法糖——不改变语言能力的便捷写法。

内存占用（64 位 JVM）：引用默认 8 字节，开启指针压缩后为 4 字节。普通对象头不压缩 16 字节，压缩后 12 字节；数组对象头不压缩 24 字节，压缩后 16 字节。

## 数组

- 声明：`int[] a;`（推荐）或 `int a[];`。
- 初始化：静态 `int[] a = {1, 2, 3};`；动态 `int[] a = new int[3];`，元素自动赋默认值（数字为 0，布尔为 false，引用为 null）。
- 长度通过 `a.length` 获取，定义后不可变。
- 多维数组：`int[][] a = new int[3][4];`。
- 数组是引用类型，赋值传的是引用，不是内容拷贝。

## 基本运算

- 算术运算：加减乘除，取模（%），自增/自减（++ --）。+ 遇字符串会转为字符串拼接。
- 比较运算：> >= < <= == !=，结果是布尔值。== 对基本类型比较值，对引用类型比较引用是否相同（即是否同一个对象）。
- 逻辑运算：与（&），或（|），非（!），异或（^），短路与（&&），短路或（||），结果是布尔值。
- 位运算：& | ^ ~ 以及移位 << >> >>>，直接操作二进制位

运算符优先级（从高到低）：括号 > 一元（++ -- ! ~）> 乘除取模 > 加减 > 移位 > 比较 > 相等（== !=）> 按位 > 逻辑（&& ||）> 三元 > 赋值。拿不准时，惯例是直接用括号 () 表达想要的顺序。

> 自增/自减是"快捷"操作：放变量前则先操作后使用，放变量后则先使用后操作。
>
> 短路是前面部分已能确定结果，后面部分就被跳过。

## 赋值与类型转换

- 声明变量就是在内存分配一块区域，赋值就是向这块区域设置具体的内容。
- 基本类型赋值：直接把内容设置到指定区域，对变量存取的都是真实内容。
- 数组或对象赋值：变量存的是位置（引用），如需存取内容则用 `.`（对象）或 `[]`（数组）。
- Java 是强类型语言，类型不兼容的变量之间不能直接赋值。

类型转换：

- boolean 不参与数值转换，无法与其他类型互相转换。
- 从小到大自动完成（隐式转换），大小顺序是 byte <（short = char）< int < long < float < double。short 和 char 虽然都是 16 位，但一个有符号、一个无符号，两者相互转换需要强制转换。
- 从大到小必须强制转换（缩小转换）：整数直接丢弃高位，浮点转整型会截尾。

作用域：

- 局部变量在方法内声明，只在方法内有效，必须赋值后才能使用。
- 成员变量在类中、方法外声明，随对象存在，会自动赋默认值（数字为 0，布尔为 false，引用为 null）。

## 方法定义

- 基本形式：`返回值类型 方法名(参数类型 参数名, ...) { 方法体 }`，无返回值用 void。
- return 返回结果并结束方法；void 方法可用不带值的 return 提前结束。
- 参数传递：基本类型传值的副本；引用类型传引用的副本——对象内容可以修改，引用本身不能替换。
- 重载（overload）：同名方法，参数列表不同即可共存，与返回值无关。
- 可变参数：`String... args`，本质是数组。

## 类定义

- 类的基本形式：`class 类名 { 成员变量; 方法; }`，是成员变量和方法的容器。
- 程序入口是某个类中的 `main` 方法，用 `java 类名` 运行；多个类时，源文件名必须与 public 类名相同。
- 包（package）是类的命名空间，避免类名冲突，目录结构与包名一致；用 import 引入其他包的类。
- 程序可以打包成 jar（本质是个 zip），指定 Main-Class 后用 `java -jar` 直接运行。

## 过程控制（条件与循环）

- 条件：if/else、switch、三元运算符（`条件 ? 值1 : 值2`）。传统 switch 的表达式值只能是 byte、short、int、char、枚举（Java 5 起）和 String（Java 7 起）；匹配到 case 后不写 break 会继续执行后面的 case（穿透）。Java 21 起，模式匹配的 switch 可以匹配任意类型。
- 循环：while、do/while（先执行一次再判断）、for、增强 for（foreach，迭代器的语法糖），循环控制用 break 和 continue。
