# Java方法的基本语法

方法即函数。数学中的函数 `y = f(x)` 描述一种映射关系：自变量 x 经过函数 f 的处理，得到因变量 y。计算机中的函数是同样的概念——输入 x，经过 f 处理，输出 y，这里的 f 就是完成特定功能的代码块。

## Java 方法的格式

```
修饰符 返回值类型 方法名(参数类型 参数1, 参数类型 参数2, ...) {
    方法体语句;
    return 返回值;
}
```

下面依次说明三个组成部分：修饰符、返回值类型、参数。

## 修饰符

### 访问修饰符

访问修饰符有 default、public、private、protected 四种：

- default（默认，不写任何修饰符）：在同一包内可见；可用于类、接口、变量、方法。
- private：在同一类内可见；可用于变量、方法。
- public：对所有类可见；可用于类、接口、变量、方法。
- protected：对同一包内的类和所有子类可见；可用于变量、方法。

> 注意：private 和 protected 不能修饰外部类，但可用于内部类。

### 非访问修饰符

- static：静态的，加在方法上也叫类方法，不需要实例化就可以调用。
- final：不可修改的，加在方法上主要目的是防止方法的内容被修改。
- abstract：抽象的，加在方法上表示一种没有任何实现的方法，需要具体子类来实现。
- synchronized：线程同步的，声明的方法同一时间只能被一个线程访问。

## 返回值类型

- 有返回值的必须使用 `return`，且返回值要和声明的类型一致。
- 无返回值的声明为 `void`，无需 `return`；也可以只写一个后面不带内容的 `return`。

## 参数

- 方法声明中用于接收数据的变量叫形式参数（形参）；实际参与运算的变量叫实际参数（实参）。
- 参数可以有 0 到多个，每个参数由数据类型和参数名组成。
- 还有可变长度参数：声明时在数据类型后面加三个点 `...`。最多只能有一个可变长参数，且必须放在最后。它是语法糖，方法内部它就是数组类型。

## 方法调用与传参

### 调用语法

- 静态方法：`类名.方法名(实参列表)`
- 实例方法：`对象.方法名(实参列表)`

### 传参规则

- 实参的个数及顺序要和形参一致，类型要匹配；类型不一致时，仅对兼容类型（如 int 转 long）编译器才会自动转换，否则编译报错。
- Java 一律是值传递。基本类型传参时，形参复制一份实参的值，形参改动不影响实参。引用类型传参时，复制的也是值——引用（地址）的副本：形参重新指向别的对象不影响实参，但两边指向同一个对象时，通过形参修改对象内容，实参同样看得到。

```java
void change(int n, int[] arr) {
    n = 100;        // 只改了形参的副本，实参不变
    arr[0] = 100;   // 通过副本改了同一个数组，实参看得到
}
```
